# **Сложно сосредоточиться**

## _Описание проекта_

Лендинг о концентрации внимания: почему сложно сосредоточиться, что мешает и какие есть простые способы вернуть фокус. Страница свёрстана по макету Figma и адаптируется под телефон, планшет и десктоп.

## Основные функции

- Переключение темы — «день», «неон» и «авто»
- Тема «авто» — подстраивается под системную схему устройства
- Адаптивная сетка — одна колонка на мобильном, две на планшете, три карточки на десктопе
- Галерея изображений — мозаика из фотографий на планшете и десктопе
- Состояния интерфейса — наведение и клавиатурный фокус у кнопок темы и ссылок

## _Структура интерфейса_

### Шапка

- Индикатор REC
- Меню выбора темы
- Заголовок «no focus»
- Подзаголовок-плашка

### Основной контент

- Почему сосредоточиться так сложно
- Что снижает концентрацию внимания
- Как концентрироваться лучше
- Блок «А можно в картинках?»

### Подвал

- Заголовок «focus»

## _Технологии_

- HTML — структура и разметка
- CSS — сетка, темы через переменные, адаптив
- JavaScript — переключение светлой, тёмной и автоматической темы
